# iThome Ironman — scoring weights

Voice is nearly the whole point of this series — "a friend sharing field notes"
fails if it reads like documentation. Weighted accordingly, at the expense of
structural variety, which the fixed recurring shape already supplies.

| dimension | weight |
|---|---|
| pattern-removal | 8 |
| voice-authenticity | 15 |
| thought-density | 12 |
| structural-variety | 7 |
| protection-fidelity | 8 |
