# E2E plan — Resources directory

## Gate outcome

Blocked by unavailable E2E tooling. This repository has no Playwright configuration, `e2e/` specs, auth fixtures, Playwright dependency, or `test:e2e*` package script. This PR does not introduce a new test framework solely to cover the Resources feature.

## Journeys requiring coverage

### Browse Resources in English and Traditional Chinese (P1)

- Actor: Public visitor
- Goal: Discover the Resources directory from site navigation and open the Design topic in the selected language.
- Pre-conditions: The statically generated site is available with the Resources collection.
- Steps: Open `/` or `/zh/`; follow Resources; follow the Design topic.
- Expected: The language-correct hub and directory render, the topic link stays in the selected locale, and resource cards expose descriptive external links that open in a new tab.
- Risk if broken: A newly promoted top-level destination is unreachable, empty, or crosses locales.
- DB/auth state: None; static content only.
- Target project: Smoke, cross-browser (target unavailable).
- Destination spec path: `e2e/smoke/resources-navigation.spec.ts` (deferred).

### Browse grouped Design catalogs (P2)

- Actor: Public visitor
- Goal: Scan the visual catalog groups and open a source for deeper browsing.
- Pre-conditions: Open `/resources/design` or `/zh/resources/design`.
- Steps: Review each named group; inspect a catalog preview; open its screenshot or title link.
- Expected: All four groups and 11 catalogs are visible, and both links open the correct source in a new tab.
- Risk if broken: Visitors cannot visually discover or reach the curated source catalogs.
- DB/auth state: None; static content only.
- Target project: Deep, Chromium (target unavailable).
- Destination spec path: `e2e/tests/resources-catalogs.spec.ts` (deferred).
