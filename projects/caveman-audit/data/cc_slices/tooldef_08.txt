## Tool: WebFetch

Fetches content from a URL and returns it in a format suitable for LLM processing. Supports HTML pages (automatically converted to readable markdown), JSON APIs (parsed and formatted), plain text, and other common web formats.

Usage:
- Use for fetching web pages, API responses, documentation, package info, etc.
- HTML content is automatically cleaned and converted to readable markdown, removing navigation, ads, and boilerplate
- For REST APIs, the raw JSON/XML response is returned and can be parsed directly
- Respects robots.txt directives and may be blocked by some sites that restrict automated access
- Has a configurable timeout for slow-responding sites (default 30 seconds)
- Content may be truncated for very large pages to fit within context limits
- Supports custom HTTP headers for authentication or content negotiation
- Follow redirects automatically (up to 5 hops)
- User-Agent identifies as Claude Code for transparency

## Tool: WebSearch

Searches the web and returns relevant results with titles, URLs, and content snippets. Uses a search engine optimized for developer and technical queries.

Usage:
- Use for finding information not available in local files or documentation
- Returns a ranked list of results with titles, URLs, and relevant snippets
- Effective for finding: documentation, Stack Overflow answers, package info, API references, error messages
- Results may not be exhaustive — try different query formulations if initial results aren't helpful
- Can use standard search operators: site:, filetype:, "exact phrase", -exclude
- Results include both organic web results and, where available, direct answers
- For GitHub-specific searches, prefer gh CLI commands via Bash tool

## Tool: LSP

Interact with a Language Server Protocol server for code intelligence features. Provides IDE-like capabilities for understanding and navigating code.

Available actions:
- diagnostics: Get errors, warnings, and info messages for a file from the language server
- hover: Get type information, documentation, and signature at a specific position
- definition: Jump to the definition of a symbol at the given position
- references: Find all references to a symbol across the codebase
- rename: Rename a symbol across all files in the project
- completions: Get code completion suggestions at a position
- signatureHelp: Get function/method signature information at a call site

Usage:
- Requires a running language server for the file's language
- Line and character positions are 0-indexed (matching LSP specification)
- For hover/definition/references, position the cursor on the symbol of interest
- Rename affects all files in the workspace — review changes carefully
- Diagnostics may take a moment to update after file changes
